### **3\. WooCommerce Bundle Product Configuration**

To configure SKU AYJ-PRD-B1 (*Ayojit Complete Academic Infrastructure Suite*) in WooCommerce:

> 1. **Required Extension:** Install **WooCommerce Product Bundles** (official plugin by WooCommerce) or **YITH WooCommerce Product Bundles**. Standard WooCommerce "Grouped Products" only group items on the shop page without creating a single bundled checkout item or applying custom package discounts.  
> 2. **Setup Steps for SKU AYJ-PRD-B1:**  
   * Create a new product named **Ayojit Complete Academic Infrastructure Suite**.  
   * Set **Product Data** to **Smart Bundle** or **Product Bundle**.  
   * Under the **Bundled Products** tab, add AYJ-PRD-C1, AYJ-PRD-C2, AYJ-PRD-C3, and AYJ-PRD-S1.  
   * Set **Pricing Scheme** to **Fixed Price**:  
     * Regular Price: ₹3,999.  
     * Sale Price: ₹2,499.  
   * Mark individual bundled items as **Virtual** so no shipping is calculated.  
   * Enable LMS auto-enrollment triggers so purchasing the bundle automatically grants access to all three courses inside LearnDash / TutorLMS while sending the service booking link.

### **4\. Service Product Type Recommendation**

For the advisory services (AYJ-PRD-S1, AYJ-PRD-S2, AYJ-PRD-S3), configure them as **Simple Products** marked as **Virtual** (and non-downloadable) rather than using a complex booking plugin inside WooCommerce.

* **Why this approach is optimal:** Using Simple \+ Virtual products avoids plugin bloat, eliminates checkout conflicts with digital courses, and allows purchase processing through native gateways.  
* **Workflow:** Upon payment completion, the customer is immediately directed to the WooCommerce "Order Received" page and receives an automated receipt email containing the embedded **Zoho Calendar** appointment booking form.
